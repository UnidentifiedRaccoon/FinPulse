## Lesson design brief

- Место урока: завершает Раздел 2 «Планирование и управление».
- Главное различие: четыре корзины — обязательное, «сначала себе», желаемое, непредвиденное.
- Типичная ошибка: держать бюджет «в уме». Feedback показывает, что черновик делает суммы видимыми.
- Real World A: как ведут бюджет другие и почему черновик надёжнее «в уме»; статистика нужна.
- Real World B: личный черновик бюджета по четырём категориям, без оценки.
- Личная рефлексия: что ты увидел(а) в своём бюджете; варианты плюс «Свой вариант».
- Микро-правило: привычка обновлять черновик; две готовые формулировки плюс «Свой вариант».
- Поведенческий мостик: завершает Раздел 2 и ведёт к будущему Разделу 3 «Инвестиции и риск».

## ЭКРАН 1. Зацепка

Узнаваемая ситуация «деньги исчезли непонятно куда» и мягкий одиночный выбор без правильного ответа.

| Элемент | Что видит пользователь |
|---|---|
| Заголовок | Куда делись деньги? |
| Текст-крючок | Конец месяца, на счёте почти пусто, а вспомнить, на что ушло, не получается. Дело не в больших тратах, а в том, что бюджет живёт только «в голове». |
| Вопрос | Узнаёшь себя? |
| Варианты | Да, к концу месяца деньги исчезают непонятно куда<br>Примерно понимаю, на что трачу, но точно не считаю<br>Я уже веду бюджет и вижу свои категории |
| Реакция | Да → Знакомо. Дальше соберём простой черновик — станет видно, куда уходят деньги.<br>Примерно понимаю → Хорошо. Черновик переведёт это «примерно» в понятную картину по категориям.<br>Уже веду бюджет → Хорошо, у тебя уже есть основа. Закрепим простую структуру из четырёх корзин. |
| Кнопка | Навести порядок |

## ЭКРАН 2. Мини-теория

Одна главная мысль: бюджет — это четыре крупные корзины, а не сложная таблица.

| Элемент | Что видит пользователь |
|---|---|
| Заголовок | Бюджет из четырёх корзин |
| Одна идея | Бюджет не обязан быть сложной таблицей. Достаточно разложить деньги по нескольким крупным корзинам — так сразу видно картину. |
| Четыре корзины | Обязательное — жильё, еда, проезд, связь, обязательные платежи.<br>«Сначала себе» — накопления и подушка.<br>Желаемое — кафе, подписки, радости.<br>Непредвиденное — запас на неожиданное. |
| Правило | Главное — чтобы доходы покрывали категории, а «сначала себе» не пропадало в конце месяца. |
| Кнопка | Понятно, дальше |

## ЭКРАН 3. Объективная практика

Категориальная сортировка: разложить расходы по четырём корзинам бюджета.

| Элемент | Что видит пользователь |
|---|---|
| Заголовок-задание | Разложи по корзинам |
| Категории | «Обязательное» · «Сначала себе» · «Желаемое» · «Непредвиденное» |
| Карточки для сортировки | Аренда квартиры → обязательное<br>Перевод на накопительный счёт → сначала себе<br>Подписка на сериалы → желаемое<br>Запас на ремонт техники → непредвиденное<br>Проезд до работы → обязательное<br>Поход в кафе → желаемое |
| Обратная связь | Хорошая работа → Когда расходы разложены по корзинам, сразу видно, на что уходят деньги и где есть запас.<br>Проверь, все так? → Почти получилось. Жильё и проезд — обязательное; перевод на накопления — «сначала себе»; кафе и подписка — желаемое; запас на ремонт — непредвиденное. |
| Кнопка | Дальше |

## ЭКРАН 4. Внешний пример / Real World A

Внешний пример: как ведут бюджет другие и почему черновик надёжнее «в уме». Ровно 3 варианта, 1 верный. Статистика по теме относится к этому экрану.

| Элемент | Что видит пользователь |
|---|---|
| Заголовок | Как ведут бюджет другие |
| Сценарий | Учёт расходов — не редкость, но почти половина ведёт его «в уме», и тогда мелкие траты теряются. Черновик на бумаге или в заметке делает суммы видимыми. |
| Статистика по теме | 53% россиян ведут учёт доходов и расходов.<br>43% ведущих учёт делают это «в уме», без записей.<br>32% учитывают расходы детально.<br>Источники: ЮMoney (2025), Moneyman / ПРАЙМ (2025). |
| Вопрос | Почему черновик надёжнее, чем бюджет «в уме»? |
| Варианты | Так бюджет выглядит солиднее<br>Видны реальные суммы по категориям, мелкие траты не теряются ✓<br>Нужно сразу скачать сложное приложение и заполнить всё идеально |
| Обратная связь | Верно! → Главный принцип: «в уме» легко недооценить мелочи, а на черновике видны реальные суммы по каждой корзине.<br>Проверь ещё раз → Черновик нужен не для солидности и не для идеальной таблицы. Он делает суммы видимыми, чтобы мелкие траты не терялись. |
| Кнопка | Применить к себе |

## ЭКРАН 5. Личное применение / Real World B

Личный черновик бюджета по четырём категориям. Не оценивается.

| Элемент | Что видит пользователь |
|---|---|
| Заголовок | Твой черновик бюджета |
| Задание | Прикинь свой бюджет на месяц по четырём корзинам. Точные суммы не нужны — достаточно примерных. |
| Поля | Доход за месяц.<br>Обязательное.<br>«Сначала себе».<br>Желаемое.<br>Непредвиденное. |
| Подсказка | Если сумма категорий больше дохода — это не провал, а сигнал, где стоит подкрутить. |
| Кнопка | Сохранить черновик |

| Элемент | Что видит пользователь |
|---|---|
| Заголовок | Что ты увидел в своём бюджете? |
| Вопрос | Когда деньги разложены по корзинам, обычно что-то удивляет. Что бросилось в глаза тебе? |

| Реакция | Даже одно наблюдение уже помогает мягко настроить корзины. |

## ЭКРАН 7. Микро-правило / привычка

Ровно две готовые variants — привычка обновлять черновик — плюс customOption «Свой вариант».

| Элемент | Что видит пользователь |
|---|---|
| Заголовок | Привычка работать с бюджетом |
| Текст | Твой бюджет работает, только если к нему возвращаться. Зафиксируй удобный для себя ритм. |
| Ровно две variants | Раз в месяц обновляю черновик по четырём корзинам и проверяю, что «сначала себе» на месте<br>Пока мягче: заглядываю в черновик хотя бы раз в пару месяцев |
