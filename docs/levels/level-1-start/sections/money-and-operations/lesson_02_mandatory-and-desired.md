## Lesson design brief

- Место урока: после урока «Куда уходят деньги», перед уроком «Безопасный платёж».
- Главное различие: обязательная трата («нужно жить») и желаемая («хочу лучше»).
- Типичная ошибка: считать желаемое «плохим» и запрещать всё подряд. Feedback показывает: цель не запрет, а осознанный выбор.
- Real World A: корзина Ани с тратами на кофе/доставку/подписки; статистика по импульсивным покупкам нужна.
- Real World B: разметка своих трат на обязательное/желаемое, без оценки.
- Личная рефлексия: что можно сократить без боли; варианты + «Свой вариант».
- Микро-правило: вопрос перед желаемой покупкой; две готовые формулировки в форме «Если..., то...» + «Свой вариант».
- Поведенческий мостик: разметка трат и правило выбора — основа для планирования и накоплений.

## ЭКРАН 1. Зацепка

Узнаваемая ситуация и мягкий одиночный выбор без правильного ответа.

| Элемент | Что видит пользователь |
|---|---|
| Заголовок | «Это мне точно нужно?» |
| Текст-крючок | В прошлом уроке ты увидел(а), куда уходят деньги. Но не все траты одинаковы: без одних не прожить, а другие — приятные, но не обязательные.<br>Аренда и проезд — это одно. А третий кофе за день или новая подписка «на всякий случай» — совсем другое. |
| Вопрос | Часто ли ты покупаешь то, без чего легко можно обойтись? |
| Варианты | Да, регулярно<br>Иногда<br>Почти никогда |
| Реакция | Любой ответ — хороший. Позволяет нам лучше познакомиться с тобой. |
| Кнопка | «Научиться различать →» |

## ЭКРАН 2. Мини-теория

Одна главная мысль: разница между обязательным и желаемым. Подаётся текстом — без видео.

| Элемент | Что видит пользователь |
|---|---|
| Заголовок | Две группы трат |
| Одна идея | Обязательные траты — то, без чего не обойтись: жильё, еда, проезд, связь, лекарства, кредиты и налоги.<br>Желаемые траты — то, что улучшает жизнь, но без чего можно прожить: развлечения, новые вещи «для радости», импульсивные покупки.<br>Желаемое — это не «плохо». Цель не запретить, а видеть разницу и выбирать осознанно. |
| Факт-иллюстрация | Простой тест: «Что будет, если этого не купить прямо сейчас?» Ничего страшного → скорее желаемое. |
| Кнопка | «Понятно, дальше →» |

## ЭКРАН 3. Объективная практика

Только категориальная сортировка: разложить траты на «обязательное» и «желаемое».

| Элемент | Что видит пользователь |
|---|---|
| Заголовок-задание | Раздели траты на две группы |
| Категории | «Обязательное» · «Желаемое» |
| Карточки для сортировки | Оплата ЖКХ → обязательное<br>Проездной на месяц → обязательное<br>Лекарства по рецепту → обязательное<br>Подписка на стриминг → желаемое<br>Новая игровая приставка → желаемое<br>Кофе в кофейне каждый день → желаемое |
| Обратная связь — верно | Верно. Обязательное — «нужно жить», желаемое — «хочу лучше». Разница не в сумме, а в необходимости. |
| Обратная связь — поправить | Проверь вопросом: «Что случится, если этого не будет?» Если ничего критичного — это желаемое. |
| Кнопка | «Проверить» → «Дальше →» |

## ЭКРАН 4. Внешний пример / Real World A

Внешний пример: корзина Ани. Ровно 3 варианта, 1 верный. Статистика по импульсивным покупкам относится к этому экрану.

| Элемент | Что видит пользователь |
|---|---|
| Заголовок | Чужая корзина |
| Сценарий | Аня посмотрела траты за месяц и удивилась: на кофе из кофейни, доставку и подписки ушло почти 8 000 ₽ — больше, чем на всё питание дома. |
| Статистика по теме | 63% россиян имеют опыт спонтанных, импульсивных покупок (ВЦИОМ).<br>35% совершают импульсивные покупки не реже раза в месяц, 18% — каждую неделю («Долями»). |
| Вопрос | Что вернее всего поможет Ане взять эти траты под контроль? |
| Варианты | Полностью запретить себе кофе и доставку<br>Увидеть, что это желаемое, и осознанно выбрать, что оставить ✓<br>Ничего не менять — это небольшие суммы |
| Обратная связь — верно | Точно. Не запрет, а разметка: когда видишь желаемое отдельно, легко решить, что оставить. |
| Кнопка | «Применить к себе →» |

## ЭКРАН 5. Личное применение / Real World B

Личный черновик: разметка 3 своих трат на обязательное/желаемое. Не оценивается.

| Элемент | Что видит пользователь |
|---|---|
| Заголовок | Размечаем твои траты |
| Задание | Возьми 3 свои траты за последние дни (можно из дневника урока «Куда уходят деньги»). Отметь каждую: обязательная или желаемая. |
| Поля ввода | Трата 1: ___ ₽ · [обязательное / желаемое]<br>Трата 2: ___ ₽ · [обязательное / желаемое]<br>Трата 3: ___ ₽ · [обязательное / желаемое] |
| Подсказка | Это твой личный черновик. Если не уверен в точности, окей. |
| Кнопка | «Сохранить разметку →» |

## ЭКРАН 6. Личная рефлексия

Безопасный субъективный ответ + обязательный «Свой вариант». Правильного ответа нет.

| Элемент | Что видит пользователь |
|---|---|
| Заголовок | Что можно сократить без боли? |
| Вопрос | Посмотри на свои «желаемые» траты. Какую из них ты сократил(а) бы — и почти не заметил(а) разницы? |
| Варианты + «Свой вариант» | Подписки, которыми почти не пользуюсь<br>Спонтанные мелкие покупки<br>Доставка/готовая еда<br>Свой вариант |
| Реакция | Отлично. Ты не запрещаешь себе — ты делаешь выбор. Классный шаг! |
| Кнопка | «Дальше →» |

## ЭКРАН 7. Микро-правило / первый шаг

Ровно две готовые variants в форме «Если..., то...» плюс customOption «Свой вариант».

| Элемент | Что видит пользователь |
|---|---|
| Заголовок | Твоё правило выбора |
| Текст | Закрепим навык простым правилом перед покупкой. Выбери готовое — или впиши своё. |
| Ровно две variants | «Если хочу что-то купить, то сначала спрашиваю: это для жизни или для радости? Мне точно это нужно прямо сейчас?»<br>«Если покупка крупная и желаемая, то делаю паузу 1 день перед решением» |
| Третий путь | customOption.label «Свой вариант» — написать свою формулировку. |
| Итог | Сохраняется одно выбранное или написанное правило. |
| Кнопка | «Сделать моим правилом» |
