## У1.1 / Паспорт урока

| Параметр | Значение |
|---|---|
| Место в курсе | Уровень 1 «Старт» · Раздел 1 «Деньги и операции» · Урок 1 из 4 |
| Цель 3-5 мин | Увидеть свои реальные траты и осознать «утечки» |
| Главный навык | Софт-навык наблюдения + привычка фиксации трат |
| Тип мышления | Понимание -> Real World A -> личный мир |
| Проверяемость | Смешанная: объективная фиксация + субъективная оценка |
| Артефакт | Список замеченных «утечек» + микро-правило фиксации |
| Поведенческий рычаг | Эффект внимания + present bias |

## Lesson design brief

- Место урока: первый урок раздела; предыдущего нет, следующий — «Обязательное и желаемое».
- Главное различие: траты, которые замечаешь сразу, и траты, которые проходят мимо внимания.
- Типичная ошибка: «у меня почти нет трат». Feedback показывает, что утечки складываются из множества мелких трат.
- Real World A: история Кирилла, который записал траты за неделю; статистика по учёту расходов в России нужна.
- Real World B: мини-дневник на 3 свои траты за сегодня, без оценки.
- Личная рефлексия: какая трата удивила; варианты + «Свой вариант».
- Микро-правило: фиксировать траты; две готовые формулировки в форме «Я буду...» + «Свой вариант».
- Поведенческий мостик: список «утечек» и привычка фиксации — основа для урока «Обязательное и желаемое».

## ЭКРАН 1. Зацепка

Узнаваемая ситуация конца месяца и мягкий одиночный выбор без правильного ответа.

| Элемент | Что видит пользователь |
|---|---|
| Заголовок | «Деньги были... или нет?» |
| Текст-крючок | Конец месяца. Смотришь на баланс, а там почти ноль. На что ушло, непонятно... Крупных покупок вроде не было.<br><br>Так бывает почти у всех людей: деньги утекают сквозь пальцы через множество маленьких трат. |
| Вопрос | Узнаёшь себя? |
| Варианты | Да, постоянно так<br>Иногда бывает<br>Нет, я знаю, куда уходят деньги |
| Реакция из JSON-card | Да, постоянно так → Знакомо. Сейчас увидим, куда уходят деньги.<br>Иногда бывает → Бывает у многих. Давай посмотрим на мелкие траты.<br>Нет, я знаю, куда уходят деньги → Отлично — проверим это на практике. |
| Кнопка | «Разобраться, куда уходят мои деньги →» |

## ЭКРАН 2. Мини-теория

Одна главная мысль: чтобы управлять деньгами, их сначала нужно увидеть. Подаётся текстом — без видео и мультимедийных карточек.

| Элемент | Что видит пользователь |
|---|---|
| Заголовок | Куда «утекают» деньги |
| Одна идея | Большие траты мы помним. А маленькие — кофе, такси, подписка, доставка — проходят мимо внимания. За месяц из них набегает заметная сумма.<br><br>Главное правило: управлять можно только тем, что замечаешь. |
| Факт-иллюстрация | 5 трат по 200 ₽ в день — это 30 000 ₽ в месяц. Незаметно по отдельности, но ощутимо в сумме. |
| Кнопка | «Понятно, дальше →» |

## ЭКРАН 3. Объективная практика

Только категориальная сортировка: разложить траты на «замечаю сразу» и «проходит мимо внимания».

| Элемент | Что видит пользователь |
|---|---|
| Заголовок-задание | Распредели траты на две группы |
| Категории | «Замечаю сразу» · «Проходит мимо внимания» |
| Карточки для сортировки | Покупка телефона → замечаю сразу<br>Аренда жилья → замечаю сразу<br>Кофе навынос → проходит мимо<br>Подписка на сервис → проходит мимо<br>Поездка на такси → проходит мимо |
| Обратная связь — верно | Точно. Именно траты «мимо внимания» обычно и создают утечку. |
| Обратная связь — поправить | Подумай: эту трату ты замечаешь в моменте или она проходит автоматически? |
| Кнопка | «Проверить» → «Дальше →» |

## ЭКРАН 4. Внешний пример / Real World A

Внешний пример, не личные данные: история Кирилла. Ровно 3 варианта, 1 верный. Статистика по теме относится к этому экрану.

| Элемент | Что видит пользователь |
|---|---|
| Заголовок | Куда уходят деньги Кирилла? |
| Сценарий | Кирилл был уверен, что «почти не тратит». Но когда записал всё за неделю, увидел реальность: кофе, доставка и такси съели почти 4 000 ₽ — это больше, чем он ожидал. |
| Статистика по теме | 56% россиян не ведут учет доходов и расходов (НАФИ).<br>197 ₽ — средний чек за кофе навынос; одна привычка — больше 5 000 ₽ в месяц («Платформа ОФД» / Т—Ж).<br>54% пользуются платными подписками, но точную сумму назовёт только 51% (Финансы Mail). |
| Вопрос | Что помогло Кириллу увидеть эти траты? |
| Варианты | Он резко стал больше зарабатывать<br>Он просто записал все траты и увидел картину ✓<br>Он перестал пользоваться картой |
| Обратная связь — верно | Точно. Ничего не запрещая и не меняя доход, Кирилл просто увидел свои «утечки». |
| Кнопка | «Применить к себе →» |

## ЭКРАН 5. Личное применение / Real World B

Личный черновик на данных пользователя: мини-дневник на 3 траты. Не оценивается как верно/неверно.

| Элемент | Что видит пользователь |
|---|---|
| Заголовок | Твои 3 траты за сегодня |
| Задание | Вспомни и запиши 3 свои траты за сегодня: сумма и категория, без оценок «хорошо/плохо». |
| Поля ввода | Трата 1: ___ ₽ · категория [еда / транспорт / развлечения / прочее]<br>Трата 2: ___ ₽ · категория [еда / транспорт / развлечения / прочее]<br>Трата 3: ___ ₽ · категория [еда / транспорт / развлечения / прочее] |
| Подсказка | Не помнишь точно? Поставь примерно. |
| Кнопка | «Сохранить и продолжить →» |

## ЭКРАН 6. Личная рефлексия

Безопасный субъективный ответ + обязательный «Свой вариант». Правильного ответа нет.

| Элемент | Что видит пользователь |
|---|---|
| Заголовок | Что удивило? |
| Вопрос | Посмотри на свои три траты. Какая из них удивила тебя — оказалась больше или меньше, чем казалось? |
| Варианты + «Свой вариант» | Кофе/перекусы — их больше, чем думал(а)<br>Такси/доставка<br>Подписки и мелкие сервисы<br>Свой вариант |
| Реакция | Здорово, что тебе удалось заметить это! На скоростях нашей жизни — считай, достижение. |
| Кнопка | «Дальше →» |

## ЭКРАН 7. Микро-правило / первый шаг

Ровно две готовые variants в форме «Я буду...» плюс customOption «Свой вариант». Без напоминаний и расписаний.

| Элемент | Что видит пользователь |
|---|---|
| Заголовок | Твоё правило на 3 дня |
| Текст | Один маленький шаг закрепит навык. Выбери правило на ближайшие 3 дня или придумай своё. |
| Ровно две variants | «3 дня записываю каждую трату — без оценок, про наблюдение за собой»<br>«Если совершаю любую трату, то сразу отмечаю её в заметках» |
| Третий путь | customOption.label «Свой вариант» — написать свою формулировку. |
| Итог | Сохраняется одно выбранное или написанное правило. |
| Кнопка | «Сделать моим правилом» |
