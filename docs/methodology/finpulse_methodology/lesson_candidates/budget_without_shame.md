## Module Sketch

Source title: "Бюджет без стыда".

Core framing: budget is not a prohibition; it is a map of choice.

Suggested sequence:

- mini-theory: budget as a map of choice;
- memory: income, expense, required expense, spontaneous expense;
- understanding: why "I remember everything in my head" often fails;
- real world: find three expense categories in a banking app for the week;
- personal world: which category surprised the user;
- habit: five minutes on Sunday for reviewing expenses.

Develops: hard skills, psychology, habits.

## Basket Exercise Source

The source exercise "Разложи по корзинам" asks the user to sort expenses:

- required;
- optional;
- regular;
- one-time;
- spontaneous;
- investment in self.

This supports budgeting because the user learns to distinguish income and
expense types, use a budget for planning, and discuss financial planning methods
with family.

Runtime note: sorting is a source pattern, not a current runtime card type.
Adapt only through supported card types or keep as supplemental methodology.

## No-Shame Design Rules

- Use errors as training, not failure.
- Avoid punishment and shame in finance topics.
- Ask safe personal questions; ranges and option choices are safer than exact
  amounts for sensitive topics.
- Keep the first action small: one category, one weekly review, one rule.

## Result Screen Fit

A budget lesson result should state the benefit, not just correctness:

- hard skill: distinguished expense categories;
- psychology: noticed a spending area without shame;
- soft skill: checked real banking categories or statements;
- habit: chose a weekly five-minute review.

The next small action can be: choose one recurring time for expense review or
write down one category to inspect next week.

## Base Quality Checklist

- Lesson takes 3-5 minutes.
- There is one main thought.
- No long lecture blocks.
- Interaction appears in the first 30-60 seconds.
- Errors receive feedback.
- There is at least one personal or real context.
- There is a micro-rule or next step.
- The lesson has a clear result.

## Candidate Cards

1. Hook: "At the end of the week it feels like money disappeared. What would help
   first: blame yourself or see the categories?"
2. Mini-theory: budget is a map of choice, not a ban.
3. Understanding: choose which expense is required, optional, regular, or spontaneous.
4. Real world: find three categories in the banking app or statement.
5. Personal world: choose which category surprised you.
6. Micro-rule: choose a weekly five-minute review time.

Keep this candidate general and educational. Do not add analytics, diagnostics,
or account-level budget tracking as part of the MVP source split.
