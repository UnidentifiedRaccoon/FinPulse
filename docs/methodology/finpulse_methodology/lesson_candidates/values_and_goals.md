## Core Methodology Additions

Values/goals lessons need several extensions beyond the base financial-training
model:

- final artifacts, especially a personal values map;
- real world B: life scenarios where money connects with values, emotions, and relationships;
- subjective checking that never marks personal values as wrong;
- return to artifacts later;
- behavioral bridges between lessons.

## Special Rules

### Do Not Judge Personal Values

Do not say that one value is wrong and another is right. The safe feedback frame:
both choices can be normal; the important thing is how the value affects financial
decisions.

### Distinguish Purchase, Need, Value, Goal

The key first-module skill:

```text
Покупка: квартира
Потребность: иметь своё стабильное место
Ценность: безопасность / комфорт / независимость
Финансовая цель: накопить первоначальный взнос
```

### Allow Several Values Behind One Desire

One desire can support different values for different people:

| Desire | Possible values |
|---|---|
| Buy an apartment | Security, independence, status, family. |
| Travel | Freedom, adventure, development, creativity. |
| Invest | Freedom, security, wealth, control. |
| Pay for education | Development, career, self-realization, family. |
| Buy an expensive car | Comfort, status, safety, pleasure. |

### Do Not Turn Reflection Into Therapy

Use soft prompts such as "choose what feels closer right now". Avoid asking the
user to resolve a major inner conflict inside a short lesson. If a topic creates
strong tension, the source allows a gentle suggestion to discuss it with a
specialist.

## Subjective Rubric

| Level | Signal | Feedback role |
|---|---|---|
| 0. Empty | Nothing chosen or written. | Offer any safe starting example. |
| 1. Desire | Only purchase or desire. | Ask why it matters. |
| 2. Need | Purchase plus reason. | Invite naming the value. |
| 3. Value | Purchase connected to value. | Mark as part of the values map. |
| 4. Financial goal | Value connected to a real goal. | Bridge to planning. |

## Quality Checklist For Values Lessons

- Preserve the difference between purchase, need, and value.
- Do not evaluate personal values as bad or good.
- Use soft reflection without pressure.
- Include a life scenario, not only abstract theory.
- Keep an artifact: value, event, rule, or map.
- Bridge to financial goals.
