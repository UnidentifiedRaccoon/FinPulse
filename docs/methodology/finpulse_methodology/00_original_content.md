# FinPulse. Дополненная методическая система для Duolingo-like приложения по финансовой грамотности

**Версия:** 0.2
**Формат:** методический документ для проектирования коротких финансовых тренировок
**Задача документа:** сохранить исходную методическую систему и дополнить её так, чтобы она лучше работала для модуля про финансовые цели, ценности, личную мотивацию и дальнейшие финансовые темы.

---

## 0. Контроль сохранности исходной методики

В этот документ включены исходные методические идеи без потери основного содержания:

- приложение строится не как «курс с тестами», а как система коротких финансовых тренировок;
- один урок длится 3–5 минут;
- базовая лестница урока: **вспомнил → понял → применил к реальному миру → применил к себе → закрепил маленьким правилом поведения**;
- каждое упражнение описывается двумя тегами: **тип мышления** и **что развивает**;
- базовые типы мышления: память, понимание, реальный мир, личный мир, привычка;
- базовые направления развития: психология, харды, софт-скилы, привычки;
- сохранены исходные примеры: ключевая ставка, импульсивные покупки, библиотека типов упражнений, модули «Бюджет без стыда», «Подушка безопасности», «Кредит: не только ставка», «Финансовая безопасность», Duolingo-подобная дневная тренировка, экран результата и главный продуктовый принцип.

Расширения добавлены отдельными разделами: **финальный артефакт**, **разделение реального мира на два типа**, **рубрика субъективных заданий**, **возврат к артефактам**, **методическая карточка урока**, **контроль качества**, **особенности модуля “Финансовые цели и ценности”**.

# Часть I. Исходная методическая система

## 1. Общая идея

Приложение лучше строить не как «курс с тестами», а как систему коротких финансовых тренировок.

Один урок на 3–5 минут должен вести пользователя по лестнице:

```text
вспомнил → понял → применил к реальному миру → применил к себе → закрепил маленьким правилом поведения
```

Последний шаг — **привычка / маленькое правило поведения** — важно проектировать отдельно. Привычка не всегда появляется из знания автоматически.

Методика хорошо ложится на рамку финансовой грамотности, где образовательные результаты можно мыслить через три группы:

- осведомлённость, знания и понимание;
- умения, навыки и поведение;
- личные характеристики и установки, включая уверенность и мотивацию.

Для FinPulse это означает: пользователь должен не только знать термин, но и уметь действовать в реальной финансовой ситуации, понимать собственные реакции и закреплять маленькие полезные правила.

---

## 2. Базовая модель упражнения

Каждое упражнение описывается двумя тегами.

```text
Тип мышления: память, понимание, реальный мир, личный мир, привычка.
Что развивает: психология, харды, софт-скилы, привычки.
```

Так одно и то же знание можно тренировать разными способами.

| Тип упражнения | Как выглядит в приложении | Что развивает |
|---|---|---|
| Знание / память | «Выбери определение ПСК», «Сопоставь термин и пример», «Что такое льготный период?» | Харды |
| Понимание | «Почему кредит с меньшим ежемесячным платежом может быть дороже?», «Что изменится, если срок увеличить?» | Харды + критическое мышление |
| Связь с реальным миром | «Найди ключевую ставку на сайте ЦБ», «Найди ПСК в реальном кредитном предложении», «Проверь, есть ли организация в реестре» | Софт-скилы + харды |
| Связь с личным миром | «Вспомни последнюю импульсивную покупку», «Какое чувство было перед покупкой?», «Какая финансовая цель пострадала?» | Психология + саморефлексия |
| Привычка / правило | «Выбери правило: покупки дороже 3 000 ₽ — через 24 часа», «Настрой день для проверки расходов», «Запланируй автоперевод на накопления» | Привычки |

Пример с ключевой ставкой хорошо подходит для слоя «реальный мир»: пользователь не заучивает цифру навсегда, а учится находить её в официальном источнике. В исходной методике приводится пример: на странице Банка России на 06.05.2026 указана ключевая ставка 14,50% годовых. Для приложения важнее не само значение, а навык проверки актуального источника.

**Методическое правило:** все быстро меняющиеся значения — ключевая ставка, курсы валют, лимиты, ставки по продуктам, законы, условия банков — не надо заучивать как вечные факты. Пользователь должен тренировать навык поиска актуальной информации в надёжном источнике.

## 3. Формат короткого урока на 3–5 минут

Базовая структура урока:

### 3.1. Крючок — 20–30 секунд

Короткая жизненная ситуация.

Пример:

> Ты увидел смартфон со скидкой 40%. До зарплаты 5 дней. Купить сейчас или подождать?

### 3.2. Мини-теория — 40–60 секунд

Одна идея, не больше.

Пример:

> Импульсивная покупка часто происходит не из-за незнания цены, а из-за эмоции, рекламы или давления окружения.

### 3.3. Тренировка понимания — 60 секунд

Пользователь сортирует покупки, выбирает объяснение, находит ошибку в рассуждении.

### 3.4. Реальный мир — 60–90 секунд

Пользователь ищет или проверяет что-то во внешней среде:

- ставку;
- комиссию;
- ПСК;
- срок;
- лимит;
- условие возврата;
- страховку;
- автоплатёж;
- подписку;
- источник информации.

### 3.5. Личный мир — 60 секунд

Маленькая рефлексия.

Пример:

> Вспомни свою последнюю спонтанную покупку. Что было триггером: скидка, стресс, скука, желание наградить себя, давление друзей?

### 3.6. Микро-правило — 20–30 секунд

Пользователь выбирает или формулирует правило.

Пример:

> Перед покупкой дороже X ₽ я жду 24 часа и сравниваю 2 альтернативы.

---

## 4. Пример полноценного урока: «Импульсивные покупки»

### Цель урока

Пользователь понимает, что импульсивная покупка — это не просто «слабая сила воли», а связка триггера, эмоции, контекста и отсутствия правила.

### Карточка 1. Память

**Вопрос:**
Что из этого относится к необязательным расходам?

**Варианты:**

A. Оплата аренды
B. Лекарства по назначению врача
C. Новый чехол для телефона, когда старый целый
D. Коммунальные платежи

**Ответ:** C.

**Что тренирует:** харды.

---

### Карточка 2. Понимание

**Ситуация:**
У тебя есть цель — накопить 30 000 ₽ на отпуск. В магазине акция: «только сегодня». Покупка стоит 4 500 ₽. Что лучше сделать?

**Варианты:**

A. Купить сразу, потому что скидка скоро исчезнет
B. Сравнить цену в двух местах и вернуться к решению завтра
C. Взять в рассрочку, чтобы не чувствовать расход
D. Купить, а потом «как-нибудь» отложить больше

**Лучший ответ:** B.

**Обратная связь:**
Скидка не всегда равна выгоде. Выгода появляется только если вещь действительно нужна и не ломает твою финансовую цель.

**Что тренирует:** понимание + психология.

---

### Карточка 3. Реальный мир

**Задание:**
Открой любой маркетплейс или интернет-магазин, не покупая товар. Найди 3 вещи:

- финальную цену;
- стоимость доставки;
- условия возврата.

**Вопрос после задания:**
Цена на карточке товара совпала с финальной стоимостью?

**Что тренирует:** софт-скилы: проверка информации, внимательность, работа с условиями.

---

### Карточка 4. Личный мир

**Задание:**
Вспомни последнюю импульсивную покупку. Не нужно вводить точную сумму, можно выбрать диапазон:

- до 500 ₽;
- 500–2 000 ₽;
- 2 000–10 000 ₽;
- больше 10 000 ₽.

**Вопрос:**
Что сильнее всего повлияло?

**Варианты:**

- скидка;
- стресс;
- скука;
- желание наградить себя;
- давление окружения;
- страх упустить;
- другое.

**Что тренирует:** психология.

---

### Карточка 5. Привычка

**Задание:**
Выбери правило на неделю:

> Покупки дороже ___ ₽ я отправляю в список желаний и возвращаюсь к ним через 24 часа.

Или:

> Когда я хочу купить что-то незапланированное, я сначала спрашиваю: какую цель это отодвинет?

**Что тренирует:** привычки.

---

## 5. Библиотека типов упражнений

### 5.1. «Финансовые пары»

Пользователь соединяет термин и смысл.

Примеры:

| Термин | Смысл |
|---|---|
| ПСК | полная стоимость кредита |
| Ликвидность | насколько быстро можно превратить актив в деньги |
| Диверсификация | распределение денег между разными инструментами |
| Инфляция | снижение покупательной способности денег |

**Подходит для:** хардов.

---

### 5.2. «Разложи по корзинам»

Пользователь сортирует расходы:

- обязательные;
- необязательные;
- регулярные;
- разовые;
- спонтанные;
- инвестиции в себя.

Это хорошо подходит для темы бюджета: пользователь учится различать виды доходов и расходов, использовать бюджет при планировании и обсуждать методы финансового планирования с семьёй.

---

### 5.3. «Найди подвох»

Показывается рекламный баннер:

> Доходность 35% годовых. Гарантия. Без риска. Только сегодня.

Пользователь тапает по красным флагам:

- «гарантия»;
- «без риска»;
- «только сегодня»;
- «слишком высокая доходность».

**Развивает:** харды, критическое мышление и финансовую безопасность.

---

### 5.4. «Выбери вопрос консультанту»

Симулятор диалога с банком, страховой или брокером.

**Ситуация:**
Ты выбираешь вклад.

**Нужно выбрать 3 вопроса:**

- Есть ли капитализация?
- Можно ли пополнять?
- Что будет при досрочном снятии?
- Какая эффективная ставка?
- Какие комиссии и налоги?

**Развивает:** софт-скилы — умение спрашивать, уточнять, не стесняться непонимания.

---

### 5.5. «Проверь источник»

Пользователь видит утверждение:

> Банк X предлагает вклад под 2 раза выше ключевой ставки. Это точно безопасно.

**Задание:**

- найти ключевую ставку на сайте ЦБ;
- найти, является ли организация банком;
- объяснить, почему высокая доходность может означать повышенный риск.

**Развивает:** связь с реальным миром.

---

### 5.6. «Мини-калькулятор»

Пример:

> Ты кладёшь 100 000 ₽ под 12% годовых на год. Сколько будет процентов до налогов?

Усложнения:

- А если вклад на 6 месяцев?
- А если проценты капитализируются ежемесячно?
- А если инфляция выше доходности?

**Развивает:** харды и понимание.

---

### 5.7. «Мой финансовый выбор»

Пользователь выбирает свою ситуацию:

- я коплю;
- я закрываю кредит;
- я хочу инвестировать;
- я часто трачу импульсивно;
- я боюсь разбираться в деньгах.

После этого приложение даёт персонализированный микро-кейс.

**Развивает:** психологию и чувство контроля.

---

### 5.8. «Сценарий с последствиями»

Пользователь принимает решение, а приложение показывает последствия через:

- 1 неделю;
- 1 месяц;
- 1 год.

Примеры сценариев:

- взять микрозайм до зарплаты или сократить необязательные расходы;
- купить в рассрочку или накопить за 3 месяца;
- погасить кредит досрочно или оставить деньги без подушки безопасности.

**Развивает:** понимание связи краткосрочных и долгосрочных последствий.

---

### 5.9. «Чек-лист перед действием»

**Перед кредитом:**

- ПСК нашёл?
- Ежемесячный платёж посчитал?
- Штрафы и комиссии проверил?
- Страховку понял?
- Что будет при потере дохода — продумал?

**Перед инвестицией:**

- Риск понял?
- Гарантий нет?
- Срок цели совпадает с инструментом?
- Комиссии понял?
- Деньги не последние?

**Смысл:** упражнение превращает знание в привычку.

---

### 5.10. «Финансовая репетиция разговора»

Пользователь тренируется говорить:

- с партнёром о семейном бюджете;
- с банком о комиссии;
- с работодателем о доходе;
- с продавцом о возврате;
- с родственником о займе.

Пример задания:

> Тебе неудобно сказать близкому человеку, что ты не готов дать деньги в долг. Выбери формулировку, которая сохраняет границу и отношения.

**Развивает:** софт-скилы и психологическую устойчивость.

## 6. Примеры модулей

### 6.1. Модуль «Бюджет без стыда»

**Мини-теория:** бюджет — это не запрет, а карта выбора.
**Память:** что такое доход, расход, обязательный расход, спонтанный расход.
**Понимание:** почему «я всё помню в голове» часто не работает.
**Реальный мир:** найди в банковском приложении 3 категории расходов за неделю.
**Личный мир:** какая категория удивила?
**Привычка:** 5 минут в воскресенье на обзор расходов.

**Развивает:** харды, психологию, привычки.

---

### 6.2. Модуль «Подушка безопасности»

**Мини-теория:** подушка — это не инвестиция, а защита от резкого ухудшения ситуации.
**Память:** сколько месяцев расходов может покрывать подушка.
**Понимание:** почему деньги на подушку должны быть доступны быстро.
**Реальный мир:** сравни вклад, накопительный счёт и наличные по доступности.
**Личный мир:** какой минимальный первый шаг — 500 ₽, 1 000 ₽, 5% дохода?
**Привычка:** автоперевод после зарплаты.

Актуальная рамка для взрослых включает цели сбережений, характеристики сберегательных продуктов, риски, издержки, доходность, а также регулярное сбережение части дохода на разные цели.

---

### 6.3. Модуль «Кредит: не только ставка»

**Мини-теория:** ежемесячный платёж — это не вся стоимость кредита.
**Память:** ставка, ПСК, срок, комиссия, штраф, залог.
**Понимание:** почему кредит на больший срок может иметь меньший платёж, но большую переплату.
**Реальный мир:** найди ПСК в кредитном предложении.
**Личный мир:** какой платёж будет безопасным при твоём доходе? Можно вводить не точную сумму, а диапазон.
**Привычка:** перед любым кредитом проверять ПСК, переплату и сценарий потери дохода.

**Развивает:** харды, самоконтроль, планирование.

---

### 6.4. Модуль «Финансовая безопасность»

**Мини-теория:** мошенники давят на скорость, страх и секретность.
**Память:** какие данные нельзя сообщать.
**Понимание:** найди признаки мошенничества в сообщении.
**Реальный мир:** проверь сайт, номер, лицензию или приложение.
**Личный мир:** где у тебя слабое место — пароли, лимиты, доверчивость к звонкам, переходы по ссылкам?
**Привычка:** раз в месяц проверять лимиты, подписки, уведомления и актуальность приложений.

Актуальная рамка для взрослых отдельно описывает финансовую безопасность: последствия подписания документов, проверку организаций, защиту личных данных и умение оценивать запросы от имени финансовых компаний на подлинность или мошеннический характер.

## 7. Как связать упражнения с четырьмя направлениями развития

### 7.1. Психология

Здесь важны не лекции, а мягкие вопросы:

- Что я чувствую, когда смотрю на деньги?
- Какие покупки я делаю от усталости?
- Какие финансовые темы я избегаю?
- Какая установка мешает: «я всё равно не разберусь», «деньги — это сложно», «копить бессмысленно»?

Упражнения должны снижать стыд и повышать ощущение контроля.

---

### 7.2. Харды

Это факты, формулы, термины и расчёты:

- ПСК;
- сложный процент;
- инфляция;
- номинальная и реальная доходность;
- налоги;
- страхование вкладов;
- кредитная нагрузка;
- разница между вкладом, накопительным счётом, облигацией, акцией.

Здесь подходят тесты, карточки, калькуляторы, сортировки и задачи.

---

### 7.3. Софт-скилы

Это умение действовать в финансовой среде:

- найти официальный источник;
- задать вопрос консультанту;
- сравнить предложения;
- прочитать договор;
- обсудить бюджет с семьёй;
- отказать в неудобной финансовой просьбе;
- подать жалобу;
- не принимать решение под давлением.

Здесь нужны диалоговые тренажёры, сценарии, чек-листы и задания «найди в реальном мире».

---

### 7.4. Привычки

Привычка должна быть маленькой, конкретной и повторяемой:

- После зарплаты перевожу 5% на цель.
- Каждое воскресенье смотрю расходы за неделю.
- Покупки дороже X ₽ — только после паузы 24 часа.
- Раз в месяц проверяю подписки.
- Перед кредитом считаю не платёж, а полную переплату.
- Перед инвестицией проверяю риск, срок и комиссии.

## 8. Duolingo-подобная механика

Дневная тренировка может выглядеть так:

```text
2 карточки на повторение — термины, формулы, красные флаги.
1 карточка на понимание — жизненный сценарий.
1 карточка на реальный мир — проверить источник, найти условие, сравнить предложение.
1 карточка на личный мир — короткая рефлексия или выбор правила.
1 микро-действие — добавить в список, включить напоминание, выбрать день проверки бюджета.
```

Вместо одного общего XP лучше показывать четыре шкалы:

| Шкала | Что означает |
|---|---|
| Знания | понимаю термины и формулы |
| Решения | умею выбирать в сценариях |
| Действия | умею искать, сравнивать, спрашивать |
| Привычки | делаю маленькие регулярные шаги |

Важно: в финансах лучше избегать наказания и стыда. Не «ты потерял жизни, потому что ошибся», а:

> Это типичная ошибка. Давай натренируем её ещё раз.

## 9. Пример экрана результата после урока

После урока пользователь видит не только «правильно / неправильно», а пользу:

```text
Сегодня ты потренировал:

Харды: понял разницу между скидкой и выгодой.

Привычка: выбрал правило паузы 24 часа.

Добавь одну желаемую покупку в список ожидания вместо покупки сегодня.
```

## 10. Главный продуктовый принцип

Самая сильная идея: каждая тема должна заканчиваться не тестом, а маленьким изменением поведения.

Не просто:

> Что такое инфляция?

А:

> Проверь, не лежит ли твоя цель в инструменте, доходность которого ниже инфляции.

Не просто:

> Что такое кредит?

А:

> Перед кредитом найди ПСК и посчитай переплату.

Не просто:

> Что такое бюджет?

А:

> Выбери один день недели для 5-минутной проверки расходов.

Не просто:

> Что такое финансовая безопасность?

А:

> Поставь лимит на онлайн-операции или проверь подписки.

Так приложение развивает не только финансовую грамотность, но и финансовое поведение.

# Часть II. Расширения методической системы

## 11. Что нужно добавить к исходной системе

Исходная система сильна для тем бюджета, кредитов, накоплений, финансовой безопасности и инвестиций. Для первого модуля про ценности и финансовые цели нужно добавить несколько элементов.

### 11.1. Новый слой: финальный артефакт

Финансовое приложение должно не только проверять знания, но и накапливать личные результаты пользователя.

**Финальный артефакт** — это сохранённый результат урока или юнита, к которому приложение может вернуться позже.

Примеры артефактов:

| Тема | Финальный артефакт |
|---|---|
| Ценности | карта личных ценностей |
| Финансовые цели | список целей с причиной и сроком |
| Бюджет | черновик категорий расходов |
| Подушка безопасности | цель по сумме подушки и первый шаг |
| Кредит | чек-лист перед кредитом |
| Инвестиции | профиль срока, риска и цели |
| Безопасность | персональный чек-лист защиты |

Для модуля «Финансовые цели и ценности» ключевой артефакт — **карта ценностей пользователя**.

---

### 11.2. Разделить «реальный мир» на два типа

В исходной методике слой «реальный мир» в основном описан как работа с внешними финансовыми источниками: сайт ЦБ, договор, ставка, ПСК, реестр, условия продукта. Для урока про ценности этого недостаточно.

Нужно разделить «реальный мир» на два подтипа.

| Подтип | Смысл | Примеры |
|---|---|---|
| Реальный мир A: финансовая среда | Пользователь взаимодействует с внешними финансовыми источниками и условиями | найти ПСК, проверить ставку, проверить организацию, прочитать условия возврата, найти комиссию |
| Реальный мир B: жизненный финансовый сценарий | Пользователь разбирает реалистичную жизненную ситуацию, где деньги связаны с ценностями, эмоциями и отношениями | ипотека или аренда, отпуск или подушка, помощь родственнику, дорогая машина или цель, семейный спор о деньгах |

Для первого модуля про ценности особенно важен **реальный мир B**.

---

### 11.3. Отдельная рубрика для субъективных заданий

В темах ценностей, целей, мотивации, семейных денег и финансовых привычек не всегда есть один правильный ответ.

Поэтому задания делятся на три типа:

| Тип проверки | Где используется | Как оценивать |
|---|---|---|
| Объективная | термины, формулы, расчёты, красные флаги | правильно / ошибка / подсказка |
| Субъективная | ценности, цели, чувства, личные правила | выполнено / нужно уточнить / предложить пример |
| Смешанная | сценарии с лучшим ответом, диалоги, чек-листы | лучший ответ / допустимый ответ / рискованный ответ |

Для субъективных заданий не должно быть оценки «неправильно» из-за выбора ценности или желания. Оценивать можно качество связи:

```text
желание / покупка → потребность → ценность → возможная финансовая цель
```

**Субъективное задание считается выполненным, если пользователь:**

- дал личный ответ;
- объяснил «зачем мне это»;
- связал желание с потребностью;
- выбрал или сформулировал ценность;
- сохранил результат в профиль или артефакт.

---

### 11.4. Возврат к артефакту

Ценности и цели меняются. Поэтому приложение должно возвращаться к сохранённым результатам.

Примеры возвратов:

| Когда | Что спросить |
|---|---|
| Через 7 дней | «Посмотри на свои 3 ценности. Всё ещё откликаются?» |
| Через 30 дней | «Какая цель стала важнее?» |
| Перед модулем про бюджет | «Какие траты поддерживают твои ценности?» |
| Перед модулем про подушку | «Какая ценность стоит за твоей потребностью в безопасности?» |
| Перед модулем про инвестиции | «Какая цель стоит за инвестициями?» |
| После крупного решения | «Какую ценность поддержало это решение?» |

Так ранние ответы пользователя начинают работать как персональная финансовая навигация.

---

### 11.5. Поведенческий мостик между уроками

Каждый урок должен завершаться не только микро-правилом, но и мостиком к следующему уроку.

Пример:

```text
Урок: Что такое ценности
Артефакт: пользователь выбрал 5 ценностей
Мостик: в следующем уроке мы проверим, как эти ценности влияют на решение «покупать квартиру или снимать»
```

## 12. Расширенная модель упражнения

Новая модель упражнения:

```text
1. Тип мышления
2. Что развивает
3. Проверяемость
4. Контекст
5. Артефакт
6. Поведенческое правило
7. Возврат
```

### 12.1. Поля упражнения

| Поле | Что фиксируем | Пример |
|---|---|---|
| Тип мышления | память / понимание / реальный мир A / реальный мир B / личный мир / привычка / артефакт | личный мир |
| Что развивает | психология / харды / софт-скилы / привычки | психология + саморефлексия |
| Проверяемость | объективная / субъективная / смешанная | субъективная |
| Контекст | где это происходит | выбор между ипотекой и арендой |
| Артефакт | что сохраняется | выбранная ценность: свобода |
| Поведенческое правило | маленькое действие | перед крупной целью спрашивать «какая ценность за этим стоит?» |
| Возврат | когда использовать снова | в модуле про бюджет |

## 14. Правила проектирования карточек

### 14.1. Один экран — одна мысль

Плохой вариант:

> Ценности — это простые и понятные базовые вещи, на которых строится ваше мироощущение и поведение, они описывают жизненные принципы и способы взаимодействия с окружающим миром, а ещё помогают принимать финансовые решения.

Хороший вариант:

> Ценности — это то, что для тебя по-настоящему важно.

Следующая карточка:

> Деньги часто помогают защищать или усиливать ценности: безопасность, свободу, развитие, семью, комфорт.

---

### 14.2. Теория должна быстро переходить в действие

Каждые 1–2 теоретические карточки должны завершаться действием:

- выбрать;
- сопоставить;
- отсортировать;
- найти ошибку;
- ответить о себе;
- сохранить правило.

---

### 14.3. Ошибка — это тренировка, а не провал

Для финансового приложения опасны стыд и наказание. Ошибка должна звучать как типичная ситуация.

Пример:

> Многие путают покупку и ценность. Квартира — это покупка. А вот безопасность, комфорт или независимость — возможные ценности за ней.

---

### 14.4. Персональные вопросы должны быть безопасными

Не всегда нужно просить точные суммы. Можно использовать диапазоны.

Пример:

```text
до 500 ₽ / 500–2 000 ₽ / 2 000–10 000 ₽ / больше 10 000 ₽
```

Для чувствительных тем можно использовать выбор из вариантов, а не свободный ввод.

---

### 14.5. Видео — как бонус, не как обязательная основа

В мобильном формате видео лучше использовать как дополнительный материал. Основной урок должен работать через карточки и интерактивы.

---

## 15. Применение системы к модулю «Финансовые цели и ценности»

Текущий урок про базовые ценности лучше превратить не в один длинный урок, а в мини-юнит.

```text
Юнит: Деньги и ценности
Урок 1. Зачем финансовым целям нужны ценности
Урок 2. Что такое ценности
Урок 3. Почему одинаковые решения подходят не всем
Урок 4. Найди ценность за событием
Урок 5. Когда ценности конфликтуют
Урок 6. Как понять, что ценность настоящая
Урок 7. Деньги и семейные ценности
Урок 8. Практика 1M$
```

### 15.1. Как распределяется методическая система по юниту

| Урок | Главный тип мышления | Что развивает | Артефакт |
|---|---|---|---|
| 1. Зачем финансовым целям нужны ценности | понимание | мотивация + харды | первая финансовая мечта |
| 2. Что такое ценности | память + понимание | психология | 5 выбранных ценностей |
| 3. Почему одинаковые решения подходят не всем | реальный мир B | понимание + принятие решений | ценностная пара: свобода/безопасность |
| 4. Найди ценность за событием | личный мир | саморефлексия | событие → ценность |
| 5. Когда ценности конфликтуют | личный мир + сценарий | саморефлексия + выбор | приоритет 3 ценностей |
| 6. Как понять, что ценность настоящая | личный мир | критическое мышление о себе | проявление ценности в действиях |
| 7. Деньги и семейные ценности | реальный мир B + софт-скилы | коммуникация | фраза для разговора о деньгах |
| 8. Практика 1M$ | артефакт | цели + мотивация | карта ценностей |

## 16. Особые правила для уроков про ценности

### 16.1. Не оценивать личные ценности как правильные или неправильные

Нельзя говорить:

> Неправильно, свобода не должна быть важнее безопасности.

Можно говорить:

> Оба выбора нормальны. Важно понять, как эта ценность влияет на твои финансовые решения.

---

### 16.2. Различать покупку, потребность и ценность

Ключевой навык первого модуля:

```text
Покупка: квартира
Потребность: иметь своё стабильное место
Ценность: безопасность / комфорт / независимость
Финансовая цель: накопить первоначальный взнос
```

---

### 16.3. Давать несколько возможных ценностей за одним желанием

Одна покупка может поддерживать разные ценности у разных людей.

| Желание | Возможные ценности |
|---|---|
| Купить квартиру | безопасность, независимость, статус, семья |
| Путешествовать | свобода, приключения, развитие, творчество |
| Инвестировать | свобода, безопасность, богатство, контроль |
| Оплатить обучение | развитие, карьера, самореализация, семья |
| Купить дорогую машину | комфорт, статус, безопасность, удовольствие |

---

### 16.4. Не перегружать психологией

В уроках про ценности можно использовать рефлексию, но нельзя превращать приложение в терапию.

Безопасная формулировка:

> Выбери, что тебе сейчас ближе.

Небезопасная формулировка:

> Найди свой главный внутренний конфликт и реши его прямо сейчас.

Если пользователь сталкивается с тяжёлым внутренним конфликтом, приложение может предложить мягкую рекомендацию:

> Если тема вызывает сильное напряжение, её можно обсудить с психологом, коучем или другим специалистом.

---

## 17. Рубрика качества для субъективных ответов

### 17.1. Уровни качества ответа

| Уровень | Признак | Обратная связь |
|---|---|---|
| 0. Пусто | пользователь ничего не выбрал и не написал | «Можно начать с любого примера. Здесь нет неправильного желания.» |
| 1. Желание | есть только покупка или желание | «Отличный старт. Теперь добавим: зачем тебе это?» |
| 2. Потребность | есть покупка и объяснение «зачем» | «Теперь попробуем назвать ценность за этой потребностью.» |
| 3. Ценность | покупка связана с ценностью | «Хорошо. Это уже часть твоей карты ценностей.» |
| 4. Финансовая цель | ценность связана с реальной целью | «Отлично. Эту цель можно будет использовать в модуле планирования.» |

## 18. Карта прогресса пользователя

Вместо одного общего прогресса можно использовать четыре шкалы из исходной методики и добавить пятую — «личная карта».

| Шкала | Что показывает |
|---|---|
| Знания | пользователь понимает термины и факты |
| Решения | пользователь выбирает в сценариях |
| Действия | пользователь умеет проверять, сравнивать, спрашивать |
| Привычки | пользователь выбирает и повторяет маленькие правила |
| Личная карта | пользователь накапливает цели, ценности, правила, чек-листы |

## 19. Контроль качества урока

Перед публикацией каждый урок проверяется по чек-листу.

### 19.1. Базовый чек-лист

- Урок длится 3–5 минут.
- В уроке есть одна главная мысль.
- Нет длинных лекционных блоков.
- Есть интерактив в первые 30–60 секунд.
- Есть обратная связь на ошибку.
- Есть хотя бы один личный или реальный контекст.
- Есть микро-правило или следующий шаг.
- Есть понятный результат урока.

### 19.2. Чек-лист для уроков про ценности

- Сохранена разница между покупкой, потребностью и ценностью.
- Нет оценки личных ценностей как «плохих» или «хороших».
- Есть мягкая рефлексия без давления.
- Есть жизненный сценарий, а не только абстрактная теория.
- Есть сохранённый артефакт: ценность, событие, правило или карта.
- Есть мостик к финансовым целям.

### 19.3. Чек-лист для финансовых тем с внешними данными

- Быстро меняющиеся цифры не зашиты как вечные факты.
- Пользователь учится находить актуальный источник.
- Источник указан или встроен в задание.
- Есть предупреждение о рисках, если тема касается кредитов, инвестиций или финансовой безопасности.
- Нет индивидуальной финансовой рекомендации там, где нужна персональная оценка ситуации.

## 21. Мини-словарь методики

| Термин | Значение |
|---|---|
| Карточка | один экран или одно действие пользователя |
| Урок | короткая последовательность карточек на 3–5 минут |
| Юнит | группа уроков, связанных одним навыком |
| Тип мышления | когнитивный режим упражнения: память, понимание, реальный мир, личный мир, привычка, артефакт |
| Харды | финансовые знания, термины, расчёты, правила |
| Софт-скилы | умение действовать в финансовой среде и коммуникации |
| Личный мир | связь с опытом, чувствами, целями и привычками пользователя |
| Реальный мир A | работа с внешними финансовыми источниками и условиями |
| Реальный мир B | жизненные финансовые сценарии |
| Артефакт | сохранённый результат пользователя |
| Поведенческий мостик | связь урока с будущим действием или следующим уроком |

# Часть III. Итоговая версия методической системы

## 22. Финальная формула урока FinPulse

```text
Короткая ситуация
→ одна мысль
→ действие
→ обратная связь
→ жизненный или внешний контекст
→ личное применение
→ маленькое правило
→ сохранённый артефакт
→ возврат к нему позже
```

## 23. Финальная формула юнита FinPulse

```text
Юнит должен дать пользователю не только знания, но и личный результат:

1. Понять идею.
2. Узнать ключевые термины.
3. Потренироваться на сценариях.
4. Применить к своей жизни.
5. Сохранить артефакт.
6. Получить микро-правило.
7. Вернуться к результату в следующих модулях.
```

## 24. Главный вывод

Исходная методическая система уже хорошо подходит для Duolingo-like приложения по финансам. Её не нужно заменять. Её нужно расширить так, чтобы она одинаково хорошо работала и для «жёстких» тем вроде кредитов, ставок, ПСК и инвестиций, и для «мягких» тем вроде ценностей, мотивации, семейных денег и финансовых привычек.

Главное дополнение: каждый урок должен завершаться не только тестом и не только правилом, но и маленьким личным результатом, который приложение сможет использовать дальше.
