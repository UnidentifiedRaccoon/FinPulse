## 22. Урок 8. Практика 1M$

### Цель урока

Связать желания, потребности, ценности и будущие финансовые цели.

### Карточка 1. Крючок

**Текст:**

> Представь, что у тебя есть 1 миллион долларов. Важно не только «что купить», но и «какая ценность за этим стоит».

---

### Карточка 2. Ввод желания

**Задание:**
Что бы ты купил или сделал?

**Поле ввода:**

```text
Я бы: ____________________
```

**Подсказки:**

- дом;
- обучение;
- путешествие;
- бизнес;
- помощь семье;
- инвестиции;
- здоровье;
- благотворительность.

---

### Карточка 3. Потребность

**Вопрос:**
Зачем тебе это?

**Варианты-подсказки:**

- хочу чувствовать себя безопаснее;
- хочу больше свободы;
- хочу жить комфортнее;
- хочу помочь близким;
- хочу развиваться;
- хочу признания;
- хочу впечатлений;
- другое.

---

### Карточка 4. Ценность

**Вопрос:**
Какая ценность под этим лежит?

**Список:**

- безопасность;
- свобода;
- комфорт;
- семья;
- развитие;
- творчество;
- признание;
- здоровье;
- благотворительность;
- богатство / успех;
- другое.

---

### Карточка 5. Повторить 3 раза

**Задание:**
Добавь ещё 2 желания, чтобы увидеть повторяющиеся ценности.

**Шаблон:**

| Что я куплю / сделаю | Зачем мне это? | Какая ценность под этим лежит? |
|---|---|---|
|  |  |  |
|  |  |  |
|  |  |  |

---

### Карточка 6. Итог

**Вопрос:**
Какие 3 ценности повторялись чаще всего?

**Что сохраняем:** карта ценностей пользователя.
